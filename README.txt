AETHER v6 — один персонаж в кадре

Замени в корне репозитория:
  index.html
  script.js
  style.css

Замени в папке stories:
  stories/moon.js

Папку assets не изменяй — все изображения остаются прежними.

ПОВЕДЕНИЕ
• Когда говорит Рассказчик, виден только фон.
• Когда говорит Аэтер, виден только Аэтер (слева).
• Когда говорит Героиня, видна только героиня (справа).
• В остальных двух историях тоже виден только говорящий персонаж.
• Когда персонажи сменяют друг друга, сначала исчезает старый, затем появляется новый.
• Выборы, музыка, сохранения и переходы остаются прежними.

В stories/moon.js пишешь историю самостоятельно. Примеры:
  figures:'aether', speaker:'Аэтер'
  figures:'hero', speaker:'Героиня'
  figures:'none', speaker:'Рассказчик'

Значение figures:'both' больше не используется. Движок в любом случае показывает не больше одного персонажа.
