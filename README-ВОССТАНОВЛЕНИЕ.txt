AETHER — восстановление после чёрного экрана

Заменить 5 файлов по точным путям:
1. index.html
2. script.js
3. style.css
4. stories/katabasis/index.js
5. stories/katabasis/episode-01.js

Не переносить папку stories в корень дважды. В GitHub каталог должен выглядеть как stories/katabasis/index.js.
Папки assets и audio не удалять. Данные сохранений в браузере не удалять.
Проверить GitHub Settings -> Pages и обновить ссылку через CTRL+SHIFT+R (или открыть в инкогнито).

В этой версии стартовая коллекция и озвучка остаются, названия аудиофайлов сохранены.
Если возникнет новая ошибка, вместо чёрного экрана появится сообщение с причиной.
