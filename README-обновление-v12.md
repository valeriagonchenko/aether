# AETHER v12 — «Приговор звёздам» + «Катабасис»

## Как обновить GitHub Pages

Распакуй архив. Загрузи содержимое в репозиторий `aether`, сохранив пути:

- `index.html` → корень репозитория (заменить)
- `script.js` → корень (заменить)
- `style.css` → корень (заменить)
- `stories/katabasis.js` → **новый** файл в папке `stories`

Текущий файл `stories/moon.js` **не заменяй**: история «Приговор звёздам» уже подключена, пролог, эмоции, кат-сцена и изображения останутся прежними. Папку `assets` тоже не меняй.

Если GitHub Pages показывает старую страницу, обнови с Ctrl+Shift+R и проверь статус Pages/Actions.

Старые истории «Бархатное затмение» и «Пепел рассвета» удалены **из каталога и игрового кода**. PNG/SVG-файлы `assets/velvet.svg` и `assets/ashes.svg` можно удалить вручную позже: они не используются. Остальные SVG (figure-f.svg и figure.svg) пока оставь, они нужны как стандартные аватары.

Старые сохранения не удаляются автоматически — это сделано специально, чтобы не стереть историю «Приговор звёздам». Старые истории просто не показываются.

## Где писать «Катабасис»

Редактируй только `stories/katabasis.js`: описание, `characters`, `nodes` и `choices`.

У каждой сцены уникальный ключ (`start`, `doctor` и т. п.). Ссылка `next` ведёт к существующей сцене.

```js
someScene: {
  speaker: 'Рассказчик',
  text: 'Ещё одна деталь всплывает в памяти.',
  bg: 'hospital',
  next: 'decision'
},
decision: {
  speaker: 'Рассказчик',
  text: 'Как поступить?',
  bg: 'hospital',
  choices: [
    {text:'Выслушать человека',next:'empathetic',effects:{empathy:1},flag:'listened'},
    {text:'Проверить факты',next:'logical',effects:{insight:1},clues:['Новая улика']}
  ]
}
```

**Статы:** `effects:{empathy:1, insight:1, money:20}`. Отрицательное значение `money:-10` списывает деньги. Если выбор стоит денег, укажи `requires:{money:10}`: кнопка будет недоступна при недостатке средств. Исходная сумма сейчас 0, её можно изменить в `initialStats` (это демо-настройка, не сюжетный факт).

**Отношения:** после утверждения персонажей можно использовать `effects:{some_character_id:2}` — ID должен совпадать с регистрацией персонажа. Имена и портреты ещё не утверждены; 3 основных линии и 2 мини-интрижки пока указаны **как план**, но сами ещё не написаны.

**Досье игрока:** в игровом экране «Катабасиса» кнопка ◇ открывает «Моё дело», где видны характеристики, деньги, улики и отношения. Значения сохраняются в `localStorage`.

**Фоны:** сейчас стоят атмосферные CSS-заглушки `bg:'hospital'` и `bg:'night'`. Их можно заменить настоящими изображениями позднее. **Спрайты:** можно указать `sprite:'assets/character-original.png',side:'left'` или `side:'right'` для конкретного кадра. Без указанного `sprite` остаётся только фон — никаких посторонних героев игра не вставит.

**Постер:** вместо отсутствующего арта сейчас стилизованный градиент с буквой K. Когда нарисуешь арт, загрузи `assets/Katabasis-promo.png` и добавь в начале `script.js` в объект `ART` запись `katabasis:'assets/Katabasis-promo.png'`.

**Финалы:** сейчас только короткий **тестовый** пролог с двумя вариантами текста в конце. Полноценные сюжетные ветки и несколько финалов напишем отдельно.

**Сохранения:** остались локальными, облачного Firebase пока нет.
