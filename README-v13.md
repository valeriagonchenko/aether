# AETHER v13 — Катабасис: пролог

Заменить в корне репозитория GitHub: `index.html`, `style.css`, `script.js`.
В папке `stories/` заменить ТОЛЬКО `katabasis.js`.
`stories/moon.js` и остальные файлы не менять.

## Какие медиа нужны в `assets/` (имена строго совпадают)

- `Midnight Unease.mp3` — настоящий MP3, пробел в названии сохранён.
- `street.png` — широкий фон переулка.
- `mc-pain.png` — героиня после нападения.
- `cut-scene1.png` — кат-сцена с ножом.
- `hospital-night.png` — больница ночью.
- `nurse.png` — медсестра.

`hospital-day.png` и `mc-default.png` уже можно хранить там же для следующих сцен; в этом фрагменте не используются.

## Порядок пролога

1. Тёмный экран на 2,2 секунды. Игра пытается запустить `Midnight Unease.mp3` после нажатия «Начать историю» (браузер может блокировать автозвук; значок позволяет включить его вручную).
2. Улица (`street.png`), панорама слева направо в течение 11 секунд, `mc-pain.png`, реплика «Как же больно...».
3. Полноэкранная кат-сцена `cut-scene1.png`, реплика «Как я тут оказалась?..».
4. Короткая темнота/моргание на 1,55 секунды.
5. Больница ночью и медсестра: «С вами всё будет хорошо. Мы о вас позаботимся».
6. Затем продолжаются прежние **тестовые выборы** из демо-пролога; это пока не полноценная глава.

**Управление:** на репликах нажимай в любом месте; две чёрные паузы проходят автоматически.

**Музыка:** перечёркнутая нота = выключена; обычная нота = включена. Настройка выключения сохраняется в этом браузере.

**Изменение сценария:** открывай `stories/katabasis.js`. Поля `blackout`, `autoNext`, `hideDialogue`, `pan`, `sprite`, `cutscene`, `cutsceneStart`, `next` пояснены комментариями. Не нужно менять `script.js`, чтобы писать следующие реплики.

Если пролог уже был запущен в прежней версии, v13 автоматически начнёт новую версию пролога. Сохранение «Приговора звёздам» не сбрасывается.
