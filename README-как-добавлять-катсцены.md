# AETHER v10 — кат-сцены

## Что положить в GitHub

**Код:**
- `/index.html` — заменить файл в корне репозитория
- `/script.js` — заменить файл в корне
- `/style.css` — заменить файл в корне
- `/stories/moon.js` — заменить файл в папке stories

**Иллюстрация, которую ты приложила:**
- переименовать в `cutscene-aether-01.png`
- загрузить **в папку `/assets/`**: `assets/cutscene-aether-01.png`

Изображение намеренно не включено в ZIP — загрузи свой исходник самостоятельно. Остальные изображения в `assets` не трогать.

## Где кат-сцена в сюжете

В `stories/moon.js` после сцены `reveal` появятся 4 кадра:
`cinematic1` → `cinematic2` → `cinematic3` → `cinematic4` → `finalChoice`.

Первый кадр с кат-сценой мягко раскрывает изображение **сверху вниз** и **постепенно отдаляет камеру**. Переход между репликами не перезапускает анимацию, если она ещё идёт. Кат-сцена заменяет обычный фон; PNG персонажей поверх неё нет. На `finalChoice` иллюстрация растворится и вернётся привычная сцена с моделькой Аэтера.

## Как написать собственную кат-сцену

Добавь в `nodes` сценария кадры с полем `cutscene`:

```js
myCutscene1: {
  speaker: 'Рассказчик',
  text: 'Он осторожно подошёл ближе.',
  cutscene: 'assets/cutscene-aether-02.png',
  cutsceneStart: true,
  next: 'myCutscene2'
},
myCutscene2: {
  speaker: 'Аэтер',
  text: '«Я здесь».',
  cutscene: 'assets/cutscene-aether-02.png',
  next: 'afterCutscene'
},
afterCutscene: {
  speaker: 'Героиня',
  text: '«Я знаю».',
  bg: 'hall',
  next: 'meeting'
},
```

Запомни:
1. **`cutscene`** — путь к картинке в папке `assets`.
2. **`cutsceneStart: true`** — только на первом кадре; запускает появление сверху вниз и zoom-out.
3. Повторяй тот же путь в следующих репликах, пока кат-сцена нужна. Говорящий персонаж указывается через `speaker`, но обычные PNG-модельки скрываются автоматически.
4. Чтобы закончить кат-сцену, просто **не указывай `cutscene`** в следующем кадре.
5. В предыдущем кадре укажи `next: 'myCutscene1'`, иначе игра до него не дойдёт.

## Скорость и эффект появления

В конце `style.css` находятся правила `v10 • КАТ-СЦЕНЫ`:
- `cutsceneRevealDown 2.8s` — раскрытие сверху вниз за 2,8 секунды;
- `cutsceneCameraOut 3.4s` — плавное отдаление за 3,4 секунды;
- `scale(1.36)` — насколько близко камера в начале;
- `scale(1.018)` — насколько далеко камера в конце.

## Как увидеть изменение

Начни или переиграй пролог «Приговор звёздам». Кат-сцена наступает **после сообщения о колонии и обратном отсчёте, перед последним выбором**. Если сохранение уже стоит позже этой сцены, закончи пролог и пройди его заново. Для обновления кеша браузера нажми `Ctrl + Shift + R`.

Анимация работает только средствами HTML/CSS/JS — платные сервисы и видеоролики не нужны.
