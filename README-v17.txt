AETHER v17 — Выбор внешности героини для «Катабасиса»

ОБНОВЛЕНИЕ НА GITHUB
1. Распакуй ZIP.
2. Замени в КОРНЕ репозитория файлы:
   index.html
   script.js
   style.css
3. В папке assets/ должны находиться изображения под ТОЧНЫМИ именами:
   гардероб.png
   mc-default-black.png
   mc-default-red.png
   mc-default-blond.png
4. Файлы stories/katabasis.js, stories/moon.js и другие изображения НЕ МЕНЯЙ.
5. После коммита обнови GitHub Pages через Ctrl+Shift+R.

КАК РАБОТАЕТ
- Перед первым запуском Катабасиса открывается выбор героини: брюнетка, рыжая, блондинка.
- Кнопка «Начать историю» сохраняет прогресс.katabasis.appearance (black/red/blond).
- При «Продолжить историю» выбор не предлагается повторно.
- Старые сохранения без appearance увидят выбор один раз, прогресс не потеряется.
- При повторном прохождении можно снова выбрать внешность.
- Все обычные реплики Героини используют сохранённый спрайт, если не указан особый спрайт.
- Для раненой героини есть только mc-pain.png (брюнетка). Для рыжей и блондинки
  в сцене ранения используется их обычный спрайт до появления отдельных вариантов.
- Отдельные CG-кат-сцены (cutscene) не меняют внешний вид автоматически.

РАБОТА С НОВЫМИ СЦЕНАМИ
В stories/katabasis.js просто пишите:
  scene1: {
    speaker: 'Героиня',
    text: 'Моя реплика.',
    bg: 'hospitalDay',
    side: 'right',
    next: 'scene2'
  },
Движок сам выберет файл персонажа, выбранный игроком.
При необходимости специальный спрайт (например, травма/особая одежда) можно
задать через sprite; собственные особые спрайты не заменяются движком.

Сохранение: localStorage (не Firebase).
