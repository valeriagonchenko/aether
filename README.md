# AETHER — серый прототип визуальной новеллы

Небольшое браузерное приложение без сборки и внешних JS-библиотек, вдохновлённое серебристой, космической эстетикой референсов.

## Запуск

Откройте `index.html` в браузере. Всё работает без веб-сервера; интернет нужен только для загрузки дополнительных веб-шрифтов (при отсутствии интернета используются системные аналоги).

## Что уже работает

- Экран загрузки с прогрессом и возможностью пропуска.
- Главное меню с тремя историями.
- Профиль: псевдоним, 8 аватаров, любимая история и до трёх любимых персонажей.
- Страницы историй: описания, постер, персонажи, главы.
- Три коротких *играбельных* пролога: персонажи, фон, реплики, ветвления и выборы с последствиями.
- Показатель смелости, очки отношений и два финала на каждую историю.
- Журнал реплик, перезапуск пролога и фоновый синтезированный звук по желанию.
- Автоматическое сохранение прогресса и профиля через `localStorage`.
- Адаптация под телефон и десктоп. Программа готова для GitHub Pages.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий на GitHub.
2. Загрузите `index.html`, `style.css`, `script.js` и каталог `assets` **в корень** репозитория.
3. В настройках репозитория откройте **Settings → Pages**.
4. Выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем сохраните.
5. GitHub выдаст ссылку вида `https://имя.github.io/репозиторий/`.

## Важно

Это прототип без настоящих учётных записей: нет авторизации, облачных сохранений и Google Sheets/Firebase. Прогресс не переносится на другое устройство и может пропасть при удалении данных браузера. Визуальные иллюстрации здесь выполнены как простые оригинальные SVG-заглушки; замените на полноценные постеры и спрайты позже.

## Где менять содержание

- `script.js` → `STORIES`: названия, описания, диалоги, выборы и ветки сюжета.
- `script.js` → `CAST`: персонажи.
- `assets/*.svg`: фоновые иллюстрации и персонажи.
- `style.css`: цветовая палитра и оформление.

### Формат реплик

У узла сцены есть `speaker`, `text`, `figures`, `next`. Узел с `choices` содержит варианты с `text`, `next`, `effects` и `flag`. Флаги влияют на финал. В будущем удобнее вынести сценарии в отдельные JSON-файлы.
