## Коллекция

В нижнем меню появилась вкладка «Карточки». Первая карточка
«Ночь без памяти» открывается после кадра `knifeMemory` (с ножом).
Карточка «За гранью звёзд» имеет тонкое золотое обрамление и доступна
сразу как стартовый подарок — несмотря на то, что история Аэтера
сейчас скрыта из приложения.

Чтобы выдать карточку за новый кадр, добавьте в нужный node:

```js
cardReward: 'knife-memory',
```

Чтобы выдать карточку после выбора, добавьте то же свойство в объект
варианта ответа. Новые карточки сперва нужно зарегистрировать в
`COLLECTION_CARDS` в `script.js` (id, title, image, rarity и т. д.).
Награды сохраняются в localStorage, существующий прогресс не сбрасывается.
Дейлики и задания ещё не реализованы.

## Озвучка

В игровом экране рядом с нотой есть **отдельная кнопка озвучки**:
значок динамика / зачёркнутого динамика. Также настройка находится
в меню с шестерёнкой. Выбор запоминается между посещениями.

В `stories/katabasis/episode-01.js` у реплики `detectiveIntroduction`
есть закомментированный пример. Добавьте в GitHub папку `audio/episode-01`
(относительно корня репозитория), поместите туда MP3 и уберите `//`:

```js
detectiveIntroduction: {
  speaker: 'Детектив',
  text: 'Доброе утро. Я веду расследование...',
  bg: 'hospitalDay',
  sprite: 'assets/detective.png',
  side: 'left',
  voice: 'audio/episode-01/detective-001.mp3',
  next: 'police'
},
```

В каждом node можно прописывать свой `voice`. Только файл текущей
реплики запрашивается по необходимости, а при переходе к следующему
кадру текущая озвучка прерывается. Музыка — независимый канал.
Если `voice` не указан, реплика остаётся без озвучки. Если путь неправильный
или браузер запретил воспроизведение, игра продолжает работать без звука.
На мобильном устройстве автоматический старт может зависеть от разрешений
браузера; обязательно проверяйте на телефоне.
